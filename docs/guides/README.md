## App help and extended guides

Short, offline help remains in `Viku/Documentation/Content/en.lproj/` and
`Viku/Documentation/Content/es.lproj/`. App help should lead with what the user can
do, give practical steps or an example, and retain essential privacy information,
limitations, and recovery advice.

Use these extended guides for implementation explanations, reference rules,
less common troubleshooting cases, and the full compatibility policy. When
behavior changes, update the relevant content in both layers and both languages;
the short articles are curated summaries, not generated copies.

Keep article filenames stable so existing references continue to work. App help
does not link to an unpublished website; add direct links to the relevant extended
articles when a documentation site is available. Essential instructions should
remain bundled and readable offline.
