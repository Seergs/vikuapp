# Server Compatibility

Viku adapts to the features your Vikunja server supports. You don't need to choose an API version or change compatibility settings.

## Keep your server up to date

For long-term compatibility, keep your server on Vikunja **2.4.0 or later**. Older servers remain supported for now, but support is planned to end after a transition period following Vikunja 4.0.

## If a feature isn't available

Your server may not support it yet. Check your server version and available updates. If someone else manages your server, ask them about updating it.
