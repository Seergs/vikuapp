# Compatibilidad del servidor

Viku se adapta a las funciones que admite tu servidor Vikunja. No necesitas elegir una versión de API ni cambiar ajustes de compatibilidad.

## Mantén tu servidor actualizado

Para mantener la compatibilidad a largo plazo, utiliza Vikunja **2.4.0 o posterior**. Los servidores anteriores siguen siendo compatibles por ahora, pero está previsto dejar de admitirlos tras un periodo de transición después de Vikunja 4.0.

## Si una función no está disponible

Es posible que tu servidor todavía no la admita. Revisa su versión y las actualizaciones disponibles. Si otra persona administra tu servidor, consúltale sobre la actualización.
